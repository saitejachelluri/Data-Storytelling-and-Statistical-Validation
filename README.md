# Data Storytelling and Statistical Validation | ApexPlanet Internship

## Project Overview

This project was completed as part of the **ApexPlanet Data Analytics Internship Program**. The objective was to perform Data Storytelling and Statistical Validation using IPL (Indian Premier League) data from 2008–2024.

The project combines Power BI dashboards and Python-based statistical analysis to transform raw data into meaningful business insights and validate findings through hypothesis testing.

## Objectives

* Analyze IPL team and player performance.
* Identify venue-based trends and patterns.
* Evaluate the impact of toss decisions on match outcomes.
* Validate insights using statistical testing.
* Present findings through effective data storytelling.

## Dashboard Insights

### Team Performance

* Mumbai Indians emerged as the most successful IPL franchise.
* Consistent team performance contributed significantly to long-term success.

### Player Performance

* Chris Gayle recorded the highest number of runs.
* Yuzvendra Chahal emerged as the leading wicket taker.

### Venue Analysis

* Eden Gardens hosted the highest number of IPL matches.
* Venue conditions influence match strategies and outcomes.

### Toss Impact Analysis

* Toss winners won approximately 50.59% of matches.
* Toss losers won approximately 49.41% of matches.

## Statistical Validation

### Hypothesis Testing

**Null Hypothesis (H₀):**
Winning the toss and winning the match are independent.

**Alternative Hypothesis (H₁):**
Winning the toss and winning the match are associated.

### Statistical Method

**Chi-Square Test of Independence**

### Results

* Significance Level (α): 0.05
* Decision: Reject Null Hypothesis

### Interpretation

The analysis indicates a statistically significant relationship between toss decisions and match outcomes.

## Key Findings

* Mumbai Indians are the most successful IPL team.
* Chris Gayle is the highest run scorer.
* Yuzvendra Chahal is the leading wicket taker.
* Eden Gardens hosted the most IPL matches.
* Toss decisions have a statistically significant relationship with match outcomes.
